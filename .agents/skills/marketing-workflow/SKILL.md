# Marketing workflow for getpullupmaster

This is a local orchestration skill, not a vendored copy of the upstream skills. Upstream: https://github.com/coreyhaines31/marketingskills . Install/select upstream skills explicitly with `npx skills add coreyhaines31/marketingskills` after reviewing them. Never claim they are installed merely because this file exists.

## When to use
When asked for a marketing audit, weekly growth review, release marketing QA, keyword/content plan, pricing or conversion experiment for **Pull Up Master acquisition website**.

## Procedure
1. Read `MARKETING_TODO.md`; check cadence and run log.
2. Verify relevant upstream skill is actually installed and load its SKILL.md. Desired capabilities: seo-audit, page-cro, copywriting. Resolve exact names from the upstream catalog.
3. Inspect project code, metadata, landing pages and instrumentation; request missing analytics instead of fabricating data.
4. Focus on: pull-up progression topics; landing page CTA.
5. Output an evidence table (finding, evidence/path, impact, confidence, effort), prioritized backlog and at most 3 testable experiments with guardrails.
6. Do not modify production, publish content, alter prices, spend on ads or add tracking without approval. Update TODO checkboxes/run log only after completing a run.
